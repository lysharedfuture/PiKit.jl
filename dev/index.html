PiKit.jl

Unofficial Julia port of the pi agent stack (pi-ai, pi-agent-core, pi-coding-agent). The verified upstream baseline, capability matrix and known deviations are tracked in upstream-compat.md.

PiKit is an independent MIT-licensed project. It is not affiliated with the upstream authors.

Packages

PackageRoleUpstream
PiAISDKmessage/content types, event streams, SSE, JSON codec, schema validation, model catalog, credentials, retry, providerspi-ai
PiAgentCoreagent loop, hooks, queues, abort, tool execution, event modelpi-agent-core
PiCodingAgentcoding tools, session v3, compaction, system prompt, AgentSession runtimepi-coding-agent (library part)
PiKitCLI (print/json/rpc/repl), config, log sink, PiKit.mainpi-coding-agent (CLI part)

Dependency direction is PiAISDK ← PiAgentCore ← PiCodingAgent ← PiKit; each package can be installed on its own.

using Pkg
Pkg.add(["PiAISDK", "PiAgentCore", "PiCodingAgent", "PiKit"])

From a checkout, Pkg.develop(path="/path/to/PiKit") resolves the subpackages through the root project.

PiAISDK

using PiAISDK

PiAISDK.set_responses!([PiAISDK.faux_text("hello")])
model = PiAISDK.find_model("faux/faux-1")
stream = PiAISDK.stream(model, PiAISDK.LLMContext(PiAISDK.AbstractMessage[PiAISDK.UserMessage("hi")]))
message = PiAISDK.result(stream)
message.content[1].text          # "hello"

PiAISDK installs no global logger: logs use the caller's logger and never write ~/.pikit state.

PiAgentCore

using PiAISDK, PiAgentCore

PiAISDK.set_responses!([PiAISDK.faux_text("done")])
agent = PiAgentCore.Agent(model=PiAISDK.find_model("faux/faux-1"),
                          tools=PiAgentCore.Tool[], system_prompt="be brief")
PiAgentCore.subscribe(agent, ev -> println(PiAgentCore.event_type(ev)))
PiAgentCore.prompt!(agent, "hello")

PiCodingAgent

using PiAISDK, PiCodingAgent

cwd = mktempdir()
PiAISDK.set_responses!([PiAISDK.faux_text("done")])
manager = PiCodingAgent.create_session(cwd; dir=cwd, in_memory=true)
session = PiCodingAgent.create_agent_session(
    cwd=cwd, model=PiAISDK.find_model("faux/faux-1"), session_manager=manager,
    settings=Dict{String,Any}("autoCompaction" => false), tools_names=String[])
PiCodingAgent.prompt!(session, "hi")
session.last_assistant.content[1].text   # "done"
PiCodingAgent.close!(session)

PiKit

julia -m PiKit -p "hi"
julia -m PiKit --mode json -p "hi"
julia -m PiKit --version

From a repository checkout, bin/pikit is equivalent. See CLI, JSON events and Sessions.
