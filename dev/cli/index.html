CLI

bin/pikit [options] [prompt], julia -m PiKit [options] [prompt], or PiKit.main() from Julia. The CLI lives in PiKit; PiCodingAgent is a library and does not export main or the argument-parsing helpers.

Exit codes: 0 success, 1 request/tool failure or unhandled error, 2 invalid arguments, 130 interrupted.

Modes

ModeTriggerstdout
text-p, --print, or non-TTY defaultfinal assistant text
json--mode jsonone JSON event per line (protocol only)
rpc--mode rpcone JSON response/event per line (protocol only)
replTTY defaultstreamed text + prompts

-- terminates option parsing; every following token is prompt text. @path reads a text file into the prompt or attaches an image (png/jpeg/gif/webp/bmp) as base64. @path is rejected in RPC mode.

Non-TTY stdin is read to EOF and prepended to the prompt. Empty prompt with a TTY starts the REPL; empty prompt without a TTY exits 0.

Configuration precedence

CLI > trusted project .pikit/settings.json > user settings > defaults. Context files (AGENTS.md, CLAUDE.md, overrides) are not affected by trust. Authentication order: --api-key, ~/.pikit/auth.json, ~/.pikit/models.json apiKey, provider environment variable.
