PiAISDK

PiAISDK is the base layer of the PiKit stack (PiAISDK ← PiAgentCore ← PiCodingAgent ← PiKit) and the Julia counterpart of @earendil-works/pi-ai. It defines the content and message types shared by every layer, the JSON codec that preserves unknown fields, SSE parsing and the AssistantMessageEventStream event model, the model catalog and credential lookup, retry and context-overflow classification, and the openai-completions, anthropic-messages, and offline faux providers. It does not depend on any other PiKit package.

Quick start

using PiAISDK

register_faux_provider!(responses=["Hello from faux"])

model = Model("faux-1", "Faux Model", "faux", "faux", "http://faux.invalid"; reasoning=true)
ctx = LLMContext(AbstractMessage[SystemMessage(""), UserMessage("hi")])

s = stream(model, ctx)
for ev in s
    ev isa TextDeltaEvent && print(ev.delta)
end
println()
println(result(s).stop_reason)  # stop

For a real provider, use a catalog model such as find_model("anthropic/claude-sonnet-4-6") and pass an API key through StreamOptions(; api_key=...) or the provider environment variable.

PiAISDK.StreamOptions — Type
StreamOptions(; kwargs...)

Options for one stream call.

Keyword arguments

  • api_key: explicit credential; otherwise resolved by the provider.
  • signal: AbortToken polled during the request.
  • headers: extra HTTP headers; a nothing value removes a default header.
  • env, identity: caller metadata carried through unchanged; the built-in providers do not read them.
  • on_payload: f(body, model) called before sending, returning a replacement body or nothing.
  • on_response: f(status, headers, model) called when the HTTP response arrives.
  • timeout_ms: read timeout; defaults to 600000 ms.
  • max_retries: retry attempts for retryable HTTP failures (default 2).
  • max_retry_delay_ms: cap for retry backoff (default 60000).
  • temperature, max_tokens: request overrides; max_tokens defaults to model.max_tokens.
  • reasoning: thinking level name, one of THINKING_LEVELS.
  • thinking_budgets: token budgets per thinking level.
  • session_id: prompt-cache key for OpenAI-compatible providers.
  • cache_retention: "none", "short" (default), or "long".

PiAISDK.stream — Method
stream(model, ctx, opts=StreamOptions()) -> AssistantMessageEventStream
stream(model, ctx; kwargs...)

Start a streaming request for ctx against model, dispatching on model.api through the PROVIDERS registry. An unknown api yields a stream with a single ErrorEvent. The call returns immediately; iterate the stream for events or call result for the final message.

Arguments

  • model: Model selecting api, provider, and endpoint.
  • ctx: LLMContext holding the conversation.
  • opts: StreamOptions; keyword form builds them.
  • kwargs...: forwarded to the StreamOptions constructor.

Example

register_faux_provider!(responses=["Hello from faux"])
model = Model("faux-1", "Faux Model", "faux", "faux", "http://faux.invalid")
ctx = LLMContext(AbstractMessage[SystemMessage(""), UserMessage("hi")])
final = result(stream(model, ctx))  # stop_reason == "stop"
