PiCodingAgent

PiCodingAgent is the coding-agent library layer of PiKit: the file and shell tools, the session v3 JSONL format, compaction, the system-prompt builder, and the AgentSession runtime. It sits between PiAgentCore and the PiKit CLI in the dependency chain PiAISDK ← PiAgentCore ← PiCodingAgent ← PiKit, and corresponds to the library part of upstream @earendil-works/pi-coding-agent.

A minimal session:

using PiAISDK, PiCodingAgent

cwd = mktempdir()
PiAISDK.set_responses!([PiAISDK.faux_text("done")])

manager = create_session(cwd; dir=cwd, in_memory=true)
session = create_agent_session(
    cwd=cwd,
    model=PiAISDK.find_model("faux/faux-1"),
    session_manager=manager,
    settings=Dict{String,Any}("autoCompaction" => false),
    tools_names=String[],
)
prompt!(session, "hi")
close!(session)

Tools are created with create_tools (or create_tool); grep is backed by ripgrep_jll and find by fd_jll, so no binaries are downloaded at runtime. Sessions are JSONL files managed by create_session, load_session, fork_session, and build_context; compact! summarizes older context when the window fills up.

PiCodingAgent.AgentSession — Type
AgentSession

High-level coding agent runtime wrapping a PiAgentCore.Agent and a SessionManager. It owns the tool set, model, reasoning level, retry policy, and event listeners.

Fields

  • agent::PiAgentCore.Agent: underlying agent.
  • session::SessionManager: persistent conversation log.
  • cwd::String: working directory.
  • model::PiAISDK.Model: active model.
  • thinking_level::String: reasoning level.
  • tools::Vector{PiAgentCore.Tool}: registered tools.
  • auto_compaction::Bool: compact automatically near the context limit.
  • retry::RetryPolicy: retry policy.
  • settings::Dict{String,Any}: merged settings.
  • listeners::Vector{Function}: event subscribers.
  • listener_lock::ReentrantLock: guards listeners.
  • last_assistant: most recent assistant message of the current run.
  • retry_attempt::Int: retries performed in the current run.
  • overflow_recovered::Bool: whether the run already recovered from overflow.
  • is_compacting::Bool: whether compaction is in progress.
  • abort_requested::Bool: whether an abort was requested.
  • agent_dir::String: agent data directory.
  • api_key::Union{Nothing,String}: optional API key override.

Conversation message recording a shell command execution. It is converted to a user message by coding_convert_to_llm unless exclude_from_context is set.

  • full_output_path::Union{Nothing,String}: path to the untruncated output file.
  • exclude_from_context::Bool: omit this message from model context.
  • timestamp::Int64: creation time in milliseconds since the epoch.

create_agent_session(; cwd=pwd(), model::PiAISDK.Model, session_manager::SessionManager,
