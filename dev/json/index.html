JSON mode

--mode json writes one JSON object per line. stdout is protocol only; logs go to the file sink (or stderr when PIKIT_LOG_STDERR=1).

The first line is the session header:

{"type":"session","version":3,"id":"...","timestamp":"...","cwd":"..."}

message_update.assistantMessageEvent never contains partial; the current message lives in message_update.message, and usage is repeated at the top level for clients that only track that event. toolcall_start additionally carries id and toolName.

willRetry on agent_end is true only when the run is not aborted, auto retry is enabled, the retry budget is not exhausted, and the last assistant message is retryable.

JSONL framing

Records are split on \n only. A leading \r is stripped. U+2028/U+2029 are not record separators.
