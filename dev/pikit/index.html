PiKit (CLI API)

PiKit is the CLI and aggregate layer. It re-exports the v0.1 module paths as const aliases and owns argument parsing, the four output modes and the log sink.

using PiKit

PiKit.AI === PiAISDK            # true
PiKit.AgentCore === PiAgentCore # true
PiKit.CodingAgent === PiCodingAgent # true

opts = PiKit.parse_cli(["-p", "--model", "faux/faux-1", "hello"])
PiKit.initial_prompt(opts)      # "hello"

Programmatic entry points:

PiKit.main()          # uses ARGS, returns the exit code

Note: Julia runs a package's @main entry point when the package is using-loaded by a script, so scripts should import PiKit instead of using PiKit.

API reference

PiKit.PiKit — Module
PiKit

CLI and aggregate layer over PiAISDK, PiAgentCore and PiCodingAgent.

Keeps the v0.1 module paths as const aliases (PiKit.AI === PiAISDK, PiKit.AgentCore === PiAgentCore, PiKit.CodingAgent === PiCodingAgent), installs the file log sink in __init__, and provides the command-line entry points (main, (@main)(args)) together with the CLI helpers.

PiKit.CLIOptions — Type
CLIOptions()

Parsed command-line options. Defaults mean "not specified on the command line"; parse_cli fills the fields from argv and resolves the output mode when it was not given.

PiKit.TagFilterLogger — Type
TagFilterLogger

File-first logger. Level selection is per _group (which each source file sets to its LOG_TAG). stderr mirroring is opt-in via PIKIT_LOG_STDERR=1.

PiKit.build_runtime — Method
build_runtime(opts::CLIOptions) -> AgentSession

Resolve the session, model, thinking level and tool set from opts and the loaded settings, then create the AgentSession used by the selected mode. --fork replaces the session with a fork at the given entry. Honours PIKIT_FAUX_RESPONSES by registering scripted faux responses before model resolution.

Throws CLIError when no model is selected or the requested model is not in the catalog.

PiKit.parse_cli — Method
parse_cli(args) -> CLIOptions

Parse command-line arguments. -- terminates option parsing; @path arguments read a text file into the prompt or attach an image as base64 (rejected in RPC mode). The mode defaults to repl on a TTY and text otherwise.

Throws CLIError for unknown options, missing values, invalid modes, thinking levels or session ids.

source
PiKit.redact — Method
redact(value)

Recursively replace values of credential-like keys with "[REDACTED]". Used before logging payloads or provider options.

source
PiKit.resolve_tool_names — Function
resolve_tool_names(opts::CLIOptions, defaults=DEFAULT_TOOL_NAMES) -> Vector{String}

Compute the tool list from the tool-related options. A list consisting only of +name/-name items modifies defaults; any other list replaces them. --no-builtin-tools starts from an empty list, --no-tools returns an empty list, and --exclude-tools is applied last with * wildcard support.

PiKit.run_json_mode — Method
run_json_mode(s::AgentSession, prompt_text::String; images=ImageContent[])

Send one prompt while streaming JSON events (session header first, then one event per line) to stdout. stdout is protocol only; logs go to the file sink. Returns the process exit code.

source
PiKit.run_print_mode — Method
run_print_mode(s::AgentSession, prompt_text::String; images=ImageContent[])

Send one prompt, print the final assistant text to stdout, and return the process exit code (0 success, 1 for error/aborted/truncated responses).

source
PiKit.run_repl_mode — Method
run_repl_mode(s::AgentSession; initial_prompt="", images=ImageContent[])

Line-oriented REPL. Streams assistant output, accepts slash commands (/help, /model, /session, …), and exits on EOF or Ctrl-D. An initial_prompt is sent before the first prompt is read.

source
PiKit.run_rpc_mode — Method
run_rpc_mode(s::AgentSession)

Read line-delimited JSON commands from stdin until EOF, writing responses and session events to stdout. Malformed lines produce an error response instead of terminating the loop. Aborts any in-flight prompt before returning 0.

json_mode_event plus retry state: agent_end events gain willRetry computed from the session retry policy and the last assistant message.
